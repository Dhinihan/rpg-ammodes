# Simeno — Notas privadas

## Resistência dos mineiros

- Quem passa muito tempo exposto ao Simeno, como os mineiros, ganha com o tempo uma leve resistência a magia. Não é óbvia, mas atrapalha magias lançadas de longe, como as de [[Hadia]] sobre [[Ahmad]] e [[Boros]].
- Ninguém sabe disso ainda. É mecanismo interno, para o Mestre usar no futuro. ([[Sessão 4]])

## Frestas que se iluminam

- Simeno derrubado numa parede faz as frestas se iluminarem só onde há a magia que [[Hadia]] ensinou a [[Noah]] para esconder portas secretas; não vale para qualquer fresta. ([[Sessão 4]])
